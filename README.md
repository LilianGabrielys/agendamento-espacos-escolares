# agendamento-espacos-escolares
Sistemas de agendamento de espaços escolares.
Tem objetivo de agendar espaços escolares como o laboratório de informática de ciências, a biblioteca e o projetor.
Tecnologias previstas: HTML, CSS, JavaScript e localStorage.
